# 日报 HTML/PDF 流程

## 1. 当前定位

本子项目不是指标总库,也不是数据观察台。它是最终日报交付层。

当前日报生产链路先按下面理解:

```text
Wind/Excel 数据刷新
  ↓
indicator_explorer 看数据变化
  ↓
人工或 AI 判断今天哪些指标值得写进日报
  ↓
macro_daily_html 生成日报 HTML
  ↓
浏览器导出 PDF
```

## 2. 当前第一版

第一版只做静态框架复刻:

- 中国一页
- 严格参照已定稿 PPT 的中国页排版
- 包含政策、流动性、经济面、需求/供给/价格、产业面和 A股/中债/港股策略
- 趋势折线图先直接复用 PPT 内嵌图片资产
- 使用浏览器 `window.print()` 导出 PDF

## 3. 与 PPT 的对应关系

最新 PPT 的两页结构对应为:

```text
slide 1: 国内宏观至资产的传导框架
  -> HTML 中国页

slide 2: 美国宏观至资产的传导框架
  -> 暂未迁移,后续再做
```

HTML 当前阶段要求优先复刻 PPT 已定稿版式,不能改成新的网页设计:

- 16:9 单页画布
- 左侧宏观传导和指标表
- 右侧资产配置和策略
- 表格中的趋势折线图必须保留
- 标注数据更新时间

## 4. 后续数据绑定

后续可逐步接入:

- `projects/indicator_explorer/data/china_display_data.json`
- 中国侧 Excel/JSON 历史序列生成的真实折线图
- 美国侧展示数据包,在美国 PPT 页迁移后接入
- AI 生成的客户经理可转述版
- 90 字 PPT/日报总结句

## 5. 后续编辑器

日报编辑器的目标是:

1. 在指标观察台发现异常变化。
2. 勾选“进入日报”。
3. 自动生成日报候选模块。
4. 用户只调整文案和保留/删除模块。
5. 点击导出 PDF。

这一步放在框架和数据绑定稳定之后。
