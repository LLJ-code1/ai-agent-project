# 日报 PPT 设计系统

本文档记录日报 PPT 的稳定设计语言。后续指标、分组和文案可以调整,但优先沿用这里的字体、颜色、组件和边界规则,避免每次换指标后版式失控。

## 1. 设计目标

日报 PPT 不是全量仪表盘,也不是研究报告正文。它要在一页内回答:

- 当前宏观传导链条处在什么状态
- 哪些指标支持这个判断
- 对资产和配置有什么含义

因此版式上要保持高信息密度,但不能牺牲可读性。核心原则是:固定设计系统,开放指标内容。

## 2. 画布和布局

- 画布比例:16:9。
- 当前 V6 参考画布:1280 x 720 渲染口径;历史 HTML 试验曾使用 1920 x 1080,两者按等比例理解。
- 主结构:左侧宏观传导,右侧资产和配置。
- 左侧顺序:流动性 -> 政策判断 -> 经济面 -> 政策或产业补充。
- 右侧顺序:资产观察 -> 策略结论/操作。
- 页面要保留顶部更新频率标识,用于解释不同指标的更新节奏。

## 3. 字体和字号

当前 V6 的主字体为 `微软雅黑`。后续优先统一为:

| 层级 | 用途 | 建议字号 |
|------|------|----------|
| 页面标题 | 国内/美国宏观至资产的传导框架 | 26pt |
| 顶部流程按钮 | 资产 / 配置 | 17pt |
| 大区标签 | 流动性 / 经济面 | 16pt |
| 指标卡标题 | 央行流动性 / 增长指标等 | 13pt |
| 指标名称 | 社融 / CPI / DR007 等 | 8-10pt |
| 当前值 | 指标当前值 | 8-10pt,加粗 |
| 较上期 | 变化值 | 8-9pt,加粗 |
| 更新时间/辅助说明 | 5月29日更新等 | 6.5-7.5pt |
| 右侧资产小表 | 资产指标行 | 7.5-8.5pt |

避免在同一层级临时改字号。需要容纳更多指标时,优先调整卡片布局或减少文案,不要随意把字号压到不可读。

## 4. 颜色

| 用途 | 颜色 |
|------|------|
| 主品牌红 | `#C8102E` |
| 正文深色 | `#1F2937` / `#111827` |
| 辅助灰 | `#6B7280` |
| 配置深蓝 | `#1E2761` |
| 正向/红色变化 | `#C00000` |
| 负向/绿色变化 | `#70AD47` |
| 浅红底 | `#FFE9E8` 或低透明度红 |
| 卡片边框 | `#E5E7EB` |

红色只用于结构标题、重点强调和按当前金融语义需要标红的变化值。绿色只用于按当前口径需要标绿的变化值。灰色用于更新时间、列名和辅助信息。

## 5. 指标卡组件

标准指标卡默认使用四列:

```text
名称 | 趋势 | 当前值 | 较上期
```

适用范围:

- 流动性指标
- 增长/需求/供给/价格等宏观指标
- 资产端基础指标
- 海外宏观指标

特殊例外:

- 国内 `产业面` 按 V6 原定结构处理,不强行套四列标准指标卡。
- `产业面` 允许保留 `行业 / 流通市值占比 / 净利润同比` 这类横向行业表结构。
- 这类特殊结构仍必须遵守统一的字体、边框、颜色和对齐规则。

## 6. 趋势图规则

- 趋势图放在表格内,采用紧凑小折线。
- 小折线只表达近几期方向,不承担完整图表解读功能。
- 不在日报页内加入坐标轴、网格线和大图表。
- 缺少同口径历史序列时,保留静态兜底,不要用不同口径数据硬替换。

## 7. 文案规则

顶部判断句要服务于阅读,不堆指标。建议:

- 流动性判断:70-90 字以内。
- 经济面判断:80-110 字以内。
- 政策条:35-55 字以内。
- 右侧策略结论:每条 1-2 行。

客户经理可转述版仍是日报 PPT 的前置步骤。先写清楚“经济怎么样 / 为什么 / 对市场有什么影响”,再压缩成 PPT 句子。

## 8. 对齐和边界

- 卡片之间保持统一间距。
- 同一大区内卡片顶边对齐。
- 表头列名、指标名、当前值、较上期要各自纵向对齐。
- 文本不能超过卡片边界;超过时优先换行或缩短文案。
- 同一页不要临时使用不同卡片圆角、边框粗细或阴影。

## 9. 可变指标原则

指标分组不是永久固定。国内可以从 `供给 / 需求 / 价格` 变成 `增长 / 价格利润 / 产业面`,海外也可以继续增加驱动指标。

真正固定的是:

- 页面主结构
- 指标卡视觉语法
- 字号层级
- 色彩语义
- 趋势图呈现方式
- 卡片数量变化时的布局测试方法

指标变动前,先查 `layout_matrix.md`,确认当前指标数量适合哪种卡片尺寸和排列方式。
